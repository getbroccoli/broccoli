# Instructions for coding agents

- This repository is a clean start. Never reference any prior codebase, former product or company names, or internal hostnames in code, comments, docs, commit messages, pull requests, release notes or issues. Present every decision on its own merits.
- Follow `docs/architecture.md`. Propose a change to it in the same pull request when a change needs one.
- Commit titles use Conventional Commits. Pull requests are squash-merged.
- Nothing internal: no secrets, no `.env` files, no internal URLs.
